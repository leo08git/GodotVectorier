# GodotVectorier
GodotVectorier is a level editor made in Godot Editor for the 2D parkour game "Vector". ([Godot 4.6.1](https://godotengine.org/download/archive/4.6.1-stable/))

**Dev note: Beta 1.1 is bugged, while I work on a fix please backup your files and install the first release instead.**

### How to install?
1. Download [Godot 4.6.1](https://godotengine.org/download/archive/4.6.1-stable/) & [The project](https://github.com/leo08git/GodotVectorier/archive/refs/tags/Beta1.1.zip)
2. Extract the project's content somewhere
3. Run Godot then import the project's `project.godot`
4. Then take a look at the [Wiki's first setup](https://github.com/leo08git/GodotVectorier/wiki/First-setup)

Now you can proceed, read more of the [wiki](https://github.com/leo08git/GodotVectorier/wiki) to know everything you can do with this!

GodotVectorier is a passion fan-made project and I am not affiliated with, nor sponsored by Nekki.
