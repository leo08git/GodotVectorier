# Features:
- Almost all classes present on Vector level system & needed to create a level.
- A diversity of objects to choose from to use in your levels
  - <img width="671" height="658" alt="imagem" src="https://github.com/user-attachments/assets/a464a645-fa16-4e38-bb30-ecf71f062855" />
- Some QOL features, for example MovementHelper to quickly create AI paths on your level
  - <img width="510" height="242" alt="imagem" src="https://github.com/user-attachments/assets/71dd2fde-7187-4429-9a5f-143526e927f8" />
- Unity scene/prefab importer (Works based on tags, meant to be used with [Unity's Vectorier](https://github.com/FlipThoseTitle/Vectorier-Unity-Editor), the feature was tested in [Kubinka0505's fork](https://github.com/kubinka0505/Vectorier) of it, though.)

- Dzip operations without the need to mess with CMDs

# Classes
It currently has:
- Image
- Platform
- Trapezoid (Slopes)
- Transform (Moving objects)
- Triggers
- Areas
- Objects (Container)
- Objects (Prefab)
- Models
- Spawn point to models
